# Nicolás Alvear — demo de estudio jurídico

Sitio estático en español, sin dependencias. Identidad y estudio ficticios.

## Vista local
Desde esta carpeta: `python -m http.server 4173 --bind 127.0.0.1 --directory dist`
Abrir http://127.0.0.1:4173 o directamente dist/index.html.

## Personalización
- Contenido, correo y redes: dist/index.html.
- Diseño adaptable: dist/styles.css.
- Menú móvil: dist/app.js.
- Retrato ficticio: dist/assets/nicolas-alvear.png.

Sin formulario ni almacenamiento de datos. El correo usa el dominio reservado .example. Instagram y LinkedIn apuntan a las páginas principales de las plataformas: reemplazar por perfiles reales al personalizar.
